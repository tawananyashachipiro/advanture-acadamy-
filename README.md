## Free Firebase preparation

The academy currently saves progress in the learner's browser and supports JSON backup/restore. Firebase is optional and has not been connected yet.

- Read [FIREBASE_SETUP.md](FIREBASE_SETUP.md) for the zero-cost Spark setup.
- Review [firestore.rules](firestore.rules) for private, per-learner progress access.
- Keep the project on Spark and do not attach billing while preparing this feature.
